# Utilities Core Module Release 0.1.1

Welcome to the latest release of the `utilities` module of [`SIGHUP Distribution`](https://github.com/sighupio/fury-distribution)
maintained by team SIGHUP.

This is a maintenance release: the module files move to the repository root and the `sd-ui`
image is pinned to a published build instead of `latest`.

## Component Images 🚢

| Component  | Supported Version | Previous Version |
| ---------- | ----------------- | ---------------- |
| `headlamp` | `0.40.1`          | No update        |

> Please refer to the individual release notes to get detailed info on the releases.

## Breaking Changes 🚨

- The module files moved out of the `ui/` directory to the repository root: the Headlamp
  package is now at `katalog/headlamp` (was `ui/katalog/headlamp`) and the examples at
  `examples/*` (were `ui/examples/*`). Update any `resources:` reference to the old path.

## Fixes 🐞

- The `sd-ui` image is pinned to `v0.1.1`, both in `deployment.yaml` and in the `images:`
  transformer of `kustomization.yaml`. Before, the transformer forced `latest`, so with
  `imagePullPolicy: IfNotPresent` the same module version could run different images.

## Update Guide 🦮

### Process

To upgrade this module from `v0.1.0` to `v0.1.1`, download the new version, update the
`katalog/headlamp` path in your `kustomization.yaml` and apply the `kustomize` project:

```bash
kustomize build | kubectl apply -f -
```
