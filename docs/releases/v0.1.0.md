# Utilities Core Module Release 0.1.0

Welcome to the first release of the `utilities` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution)
maintained by team SIGHUP.

This release introduces the `headlamp` package: the SD build of Headlamp (upstream Headlamp
server bundled with the SD plugins) together with three ready-made authentication overlays.

## Component Images 🚢

| Component  | Supported Version | Previous Version |
| ---------- | ----------------- | ---------------- |
| `headlamp` | `0.40.1`          | -                |

## New Features 🌟

- The auth-agnostic `katalog/headlamp` package: Namespace, ServiceAccount, Service and
  Deployment, with no ingress or authentication assumptions baked in.
- `examples/token-auth`: plain TLS ingress, Headlamp reaching the API server as its own
  ServiceAccount, gated by Headlamp's Kubernetes token login.
- `examples/oidc-capsule`: Headlamp behind Pomerium SSO with requests proxied through
  Capsule Proxy for per-tenant filtering.
- `examples/oidc-rbac`: Headlamp behind Pomerium SSO with OIDC group-based RBAC.

## Update Guide 🦮

### Process

To install the module run:

```bash
kustomize build | kubectl apply -f -
```
