# Utilities Core Module Release 1.0.0

Welcome to the first release of the `utilities` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution)
maintained by team SIGHUP.

This release introduces the `headlamp` package: the SD build of Headlamp (the upstream Headlamp
server bundled with the SD plugins), together with three authentication overlays you can use
as they are.

## Component Images 🚢

| Component  | Supported Version | Previous Version |
| ---------- | ----------------- | ---------------- |
| `headlamp` | `0.40.1`          | -                |

## New Features 🌟

- The `katalog/headlamp` package: Namespace, ServiceAccount, Service and Deployment. It works
  with any ingress and any authentication method.
- `examples/token-auth`: a plain TLS ingress. Headlamp calls the API server as its own
  ServiceAccount, and users log in with a Kubernetes token.
- `examples/oidc-capsule`: Headlamp behind Pomerium SSO. Requests go through Capsule Proxy,
  so each tenant sees only its own resources.
- `examples/oidc-rbac`: Headlamp behind Pomerium SSO. Access follows the RBAC bound to the
  OIDC groups of the user.
- The `sd-ui` image is pinned to `v1.0.0`, both in `deployment.yaml` and in the `images:`
  transformer of `kustomization.yaml`.

## Installation Guide 🦮

### Process

To install the module run:

```bash
kustomize build | kubectl apply -f -
```
