# Utilities Core Module Release 1.0.0

Welcome to the first release of the `utilities` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution) maintained by team SIGHUP.

This release introduces the `headlamp` package: the SD build of Headlamp (the upstream Headlamp server bundled with the SD plugins), together with three authentication overlays you can use as they are.
